# The Major System

A phonetic code: each digit maps to one or more **consonant sounds**. Vowels and the consonants
`w, h, y` are free filler. You turn a number into consonant sounds, then pad with vowels to make a
memorable word, then picture that word.

## The digit → sound map (standard)

| Digit | Sounds | Memory hook |
|---|---|---|
| 0 | s, z, soft c | "zero" starts with z |
| 1 | t, d, th | one downstroke |
| 2 | n | two downstrokes |
| 3 | m | three downstrokes (m on its side) |
| 4 | r | "four" ends in r |
| 5 | l | Roman L = 50; five fingers, thumb out = L |
| 6 | j, sh, ch, soft g | a 6 looks like a reversed J |
| 7 | k, hard c, hard g | a K is two 7s |
| 8 | f, v | cursive f looks like an 8 |
| 9 | p, b | 9 is a mirrored P |

It is **sounds, not letters** — "ph" codes 8 (f sound), double letters count once.

## Worked examples

- **32** → m, n → "**moon**" (picture a moon).
- **45** → r, l → "**rail**".
- **314** → m, t, r → "**meteor**" (vowels are free).
- **90210** → b, n, s, t, s → "**bun toss**" (or two words: "bun" 92, "toes" 010... pick clean splits).

## How to use it

1. Memorize the 10 digit→sound mappings cold (drill with `spaced-recall`).
2. Optionally build a fixed **00–99 peg list** — one stable word per two-digit number — so you never
   re-derive on the fly. This is the real speed unlock.
3. Convert the target number into words, picture them, and hand the images to `loci-encoder` to
   place along a route.

The Major System is the foundation for the Dominic and PAO systems in `pao.md`.
